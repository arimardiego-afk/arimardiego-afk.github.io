Política de Privacidade — HD Externo Online

Versão de 17 de setembro de 2026 · voltar ao início

1. Quem somos

HD Externo Online é um aplicativo pessoal, sem fins comerciais, criado para uso próprio do seu autor. Ele usa o programa livre rclone para apresentar as pastas do Google Drive do próprio usuário como uma unidade de disco no computador. Contato: arimardiego@gmail.com.

2. Que dados o aplicativo acessa

Somente os arquivos e pastas da conta do Google que a própria pessoa autoriza, por meio da permissão https://www.googleapis.com/auth/drive. Esse acesso serve a uma única finalidade: listar, abrir, enviar e baixar os arquivos do próprio usuário enquanto a unidade de disco estiver montada.

O aplicativo não acessa contatos, agenda, e-mail, fotos nem dados de outros serviços do Google.

3. Onde os dados ficam

  • Não existe servidor. O programa roda apenas no computador de quem o instala; nada trafega por sistemas do autor.
  • A ficha de acesso (token) fica gravada somente no computador do usuário, no arquivo de configuração do rclone.
  • Os arquivos que o usuário abre podem ficar guardados temporariamente em uma pasta de cache no próprio computador, para que a unidade funcione mais rápido.

4. O que o aplicativo NÃO faz

  • Não coleta, não transmite e não armazena dados pessoais em nenhum servidor.
  • Não compartilha, vende, aluga nem cede dados a terceiros.
  • Não usa os dados para publicidade.
  • Não usa os dados para treinar modelos de inteligência artificial.
  • Não permite que pessoas leiam os dados, salvo quando a lei exigir.

5. Uso limitado dos dados do Google

O uso que o HD Externo Online faz das informações recebidas das APIs do Google obedece à Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado (Limited Use).

6. Como retirar o acesso e apagar os dados

A autorização pode ser cancelada a qualquer momento em myaccount.google.com/permissions. A partir daí o aplicativo perde o acesso imediatamente. Para apagar o que ficou no computador, basta remover o remoto do rclone e a pasta de cache — nenhuma cópia permanece em outro lugar.

7. Crianças

O aplicativo não se destina a menores de 13 anos e não coleta dados deles.

8. Mudanças nesta política

Qualquer alteração passa a valer na data indicada no topo desta página, que é o endereço oficial e permanente desta política.
